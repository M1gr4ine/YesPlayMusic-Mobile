# YesPlayMusic Mobile v0.2.11

这是相对于 **v0.2.10** 的累计更新，包含歌手与专辑详情、横屏歌词待机、系统歌词、QQ 音源匹配、播放器操作及搜索体验改进。

## 歌手与专辑详情

- 新增歌手页：歌手头像、别名、简介、歌曲/专辑数量、热门歌曲、最新发行，以及按专辑、EP 和单曲分类的作品列表。
- 歌手页支持播放热门歌曲、随机播放、展开全部热门歌曲、展开简介及进入专辑。
- 新增专辑页：封面、歌手、发行年份、曲目数、总时长、简介、按序号排列的曲目和发行信息；支持全部播放、随机播放、歌曲操作以及浏览同歌手的其他专辑。
- 搜索中的歌手和专辑结果可进入对应详情页，歌曲操作菜单也增加歌手、专辑入口。
- 播放器将歌手和专辑分成两行，**专辑显示在歌手下方**，两者均可直接点击跳转。
- 点击后在原页面查询，单歌手和专辑跳转不经过中间操作弹窗；多歌手歌曲可选择目标歌手。
- 去除播放器歌手、专辑链接的触屏蓝色高亮和长按文字选中，保留键盘焦点提示。
- QQ 曲库歌曲通过网易云匹配查找歌手、专辑详情；缺少标识时按名称补查。无法找到时显示提示。
- 详情页支持逐级返回并恢复滚动位置；换歌或关闭播放器后，旧查询结果不会突然触发跳转。

## 横屏歌词待机

- 横放手机进入专用待机界面，展示大号时钟、专辑封面、歌曲信息、播放控制及大字同步歌词。
- 支持上一首/下一首、播放/暂停、收藏、播放模式、进度拖动和翻译开关。
- 提供全屏锁定：锁定横屏后，旋转手机或返回操作不会退出；解锁后恢复自动旋转。
- 隐藏系统栏；仅在待机页播放音乐时保持屏幕常亮，暂停后恢复系统息屏策略。
- 旋转时不再重建 Activity。进入待机页后暂停隐藏竖屏界面的更新和跑马灯，退出时再同步内容。
- 优化歌词位移动画，并将待机页刷新率请求限制为最高 60 Hz，减少不必要的绘制。

## 歌词与系统媒体卡片

- 新增歌词旁的 **“译”开关**，切换原文或原文加中文翻译，并保存偏好；切换时保持当前歌词行的位置。
- 更新 QQ 歌词获取方式，支持取得翻译内容；允许原文与译文时间戳有小幅偏移，过滤无翻译行的 `//` 占位符。
- 新增系统歌词开关：将当前歌词同步到系统媒体信息，供锁屏、通知栏及支持的系统媒体卡片显示。
- 歌词由后台播放服务获取和计时，离开前台后仍可推进。具体显示样式由手机系统决定。

## QQ 音源匹配与播放操作

- 改进日文、英文歌曲因中文歌手名、译名或标题附加中文说明而匹配失败的问题。
- 保留严格匹配优先，再按桌面版 UNM 的候选和时长规则补查，最后尝试仅标题搜索；继续区分现场、伴奏、混音等版本。
- 支持更多繁简中文和日文汉字形式归一化；候选无法取得播放链接时继续尝试后续候选，最多尝试 3 首。
- 播放器左侧按钮统一循环切换：**顺序播放 → 列表循环 → 单曲循环 → 随机播放**。
- 播放器右侧改为当前歌曲操作入口，集中访问收藏、添加到歌单、歌手和专辑。
- 简化播放器顶栏，移除关闭和设置按钮，保留下滑关闭操作。
- 修复迷你播放器收藏心形在播放/暂停或重新解析音源时闪烁的问题，同一首歌保持收藏状态。

## 搜索、性能与维护

- 修复关闭搜索键盘后底部导航、迷你播放器仍隐藏，以及左右切页仍不可用的问题。
- 搜索提交后主动收起键盘，并使用 Android 实际键盘可见状态同步界面。
- 页面不可见时暂停前端播放状态轮询；预编译歌曲匹配规则，减少重复工作。
- 清理未使用的 QQ 收藏、二维码登录及桥接代码路径，移除死代码。
- 整理为统一的 JavaScript/Java 测试目录，增加一键测试入口；测试直接调用生产代码，并补充播放器状态、歌词、匹配和导航回归覆盖。
