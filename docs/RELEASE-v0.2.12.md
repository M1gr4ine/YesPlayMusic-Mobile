# YesPlayMusic Mobile v0.2.12

这是相对于 **v0.2.11** 的更新，重点完善横屏播放页的电量显示、网易云自建歌单编辑，以及退出播放服务后的状态恢复；同时清理了重复和脆弱的测试。

## 网易云自建歌单编辑

- 在自建歌单中修改名称和简介、调整歌曲顺序，或勾选多首歌曲后一次移除；移除前会列出待移除歌曲供核对。
- 仅允许编辑当前登录账号创建的普通歌单；收藏歌单和“我喜欢”不提供编辑入口。前端和原生接口都会检查所有权，写入前还会读取最新歌单，拒绝权限已变化或曲目集合不完整的操作。
- 排序提交完整曲目 ID 集合并核对服务端当前列表；超过现有 500 首加载上限或无法完整读取时，不提交排序。
- 修改名称、简介、曲序或移除歌曲后，重新读取歌单确认结果。只有读回一致才报告成功；部分接受、结果未确认和读回不一致会分别说明，不会把未核实的内容当成已保存。
- 保存失败时保留编辑草稿。离开有未保存内容的页面时，可选择继续编辑或放弃；放弃后延迟中的歌手、专辑跳转仍会正常完成。
- 编辑页适配 Android 软键盘，名称和简介输入时保持当前字段可见；保存期间避免重复提交。原生编辑请求有 60 秒总时限，页面等待上限为 90 秒。

## 横屏播放与电量

- 横屏播放页显示系统电量百分比及充电状态；电量取自 Android 电池广播，并在进入页面、回到前台和电池状态变化时更新。
- 调整电池、时间和翻译控件的对齐；翻译开关可在横屏歌词中切换原文与双语显示。
- 横屏方向锁定期间，设备转动不会改变页面方向；解除方向锁定后恢复系统自动旋转。

## 播放状态恢复

- 播放服务退出或应用进程重启后，不再把上次保存的“正在播放”或缓冲状态误显示为实时播放。
- 恢复时保留当前曲目、播放队列和已保存信息，并以暂停状态显示；用户可继续播放。播放服务销毁时会清除过期的媒体状态，避免系统媒体卡片继续报告陈旧状态。

## 代码与检查精简

- 移除冗余的播放器外观测试，并清理测试支架中的未使用时钟和冗余断言；保留围绕可观察行为、歌单策略和请求期限的检查。
- 简化歌单编辑错误处理、播放曲目数据传递和歌手别名解析，删除不必要的转发包装及未使用路径。
- 本版自动检查：**JavaScript 21 项、Java 117 项通过**。

## 真机验证

- 已在 iQOO 16（V2606A）上实测本版功能：歌单编辑、键盘输入、横屏翻译与方向锁定、草稿放弃后的详情跳转，以及播放进程退出后的恢复和后台播放。
- 歌单名称、简介、曲序和歌曲移除均在官方客户端重新打开歌单后核对服务端结果；测试用临时私有歌单已删除，原有歌单和收藏数据保留。
- 横屏电量显示核对了真实充电状态和放电状态；0% 模拟导致系统关机，未列为真机通过项。测试结束后设备电量和旋转设置已恢复。
- 最终 versionCode 14 发布 APK 已先行覆盖安装到 iQOO 16，回读设备 `base.apk` 的 SHA-256 与发布文件一致；8 项页面资源和 DEX 与已完成真机回归的功能包逐字节一致。
- 更详细的功能范围、复测结果和边界见[横屏电量与歌单编辑验证记录](https://github.com/M1gr4ine/YesPlayMusic-Mobile/blob/v0.2.12/docs/VERIFICATION-landscape-playlist-editor.md)。
