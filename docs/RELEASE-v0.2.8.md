# YesPlayMusic Mobile v0.2.8

基于 [qier222/YesPlayMusic](https://github.com/qier222/YesPlayMusic) 的非官方 Android 移动版，感谢上游作者与贡献者。采用 MIT 许可证，详见仓库 LICENSE 与 NOTICE.md。

本版包含：

- 网易云音乐曲库、歌单与登录，以及 QQ 音乐搜索与音源。
- 听听、我的、搜索三个页面；我的页面展示最近播放和歌单。
- 原生后台播放、锁屏控制，以及在 iQOO 16 / OriginOS 7 上验证的原子随身听和原子岛接入。
- 底部播放条收藏、播放/暂停、播放列表和左右滑动切歌。
- 歌名下方同步显示当前歌词，长句滚动，暂停时停止。
- 调整页面切换动画，修复快速反向滑动时旧页面残留与滚动位置丢失。
- 更新对称声波图标，系统返回可逐层关闭播放列表、播放详情和歌单。

实机截图见 [仓库 README](https://github.com/M1gr4ine/YesPlayMusic-Mobile#readme)。

安装 `YesPlayMusic-Mobile-v0.2.8.apk`；可使用 `SHA256SUMS.txt` 验证安装包。该 APK 与本次实机验证安装的版本一致。

已知问题：QQ 扫码确认仍可能失败，当前可使用账号密码登录；网易云手机验证码可能遇到 `-462` 风控，建议使用扫码。其他厂商系统的媒体卡片表现尚未完整验证。
