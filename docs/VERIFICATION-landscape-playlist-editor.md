# 横屏电量与歌单编辑验证记录

日期：2026-10-18。

## 已实现

- 横屏播放页的翻译、锁定按钮位于时间右侧，按钮上方显示电池图标和电量百分比。
- 电量来自 Android `ACTION_BATTERY_CHANGED`，覆盖进入横屏、实时变化和返回前台刷新；支持充电、低电量、0% 和未知读数。
- 网易云自建歌单支持修改名称、简介，多选移除歌曲，以及调整完整歌单的歌曲顺序。
- 编辑权限由前端和原生端分别检查当前账号及歌单创建者，排除收藏歌单和“我喜欢”。
- 保存失败保留草稿；离开未保存的编辑页时提供继续编辑或放弃更改。保存期间禁用元数据输入。
- 元数据、移除和排序成功均需读取远端结果核对；未确认结果与已核实字段分别表示。单次原生编辑有 60 秒总时限，页面等待最多 90 秒。
- 排序要求完整加载且不超过现有 500 首加载上限；原生端还会核对最新完整歌曲 ID 集合。
